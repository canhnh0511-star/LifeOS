# Triage Labels

Các skill dùng năm vai trò triage chuẩn. File này ánh xạ các vai trò đó sang chuỗi label thực tế dùng trong issue tracker của repo.

| Label trong mattpocock/skills | Label trong tracker của ta | Ý nghĩa                                       |
| ----------------------------- | -------------------------- | --------------------------------------------- |
| `needs-triage`                | `needs-triage`             | Maintainer cần đánh giá issue này             |
| `needs-info`                  | `needs-info`               | Đang chờ người báo cung cấp thêm thông tin    |
| `ready-for-agent`             | `ready-for-agent`          | Đã đặc tả đầy đủ, sẵn sàng cho AFK agent      |
| `ready-for-human`             | `ready-for-human`          | Cần con người triển khai                      |
| `wontfix`                     | `wontfix`                  | Sẽ không xử lý                                |

Khi một skill nhắc tới một vai trò (ví dụ "apply the AFK-ready triage label"), dùng chuỗi label tương ứng trong bảng này.

Sửa cột bên phải cho khớp với bộ từ vựng bạn thực sự dùng.
